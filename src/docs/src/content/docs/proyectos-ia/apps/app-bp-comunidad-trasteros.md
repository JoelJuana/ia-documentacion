# app-bp-comunidad-trasteros

Simulador financiero y calculador de viabilidad económica para la inversión en naves o locales comerciales destinados a trasteros urbanos y minialmacenes de alquiler temporal.

## Características y Funcionalidades

1. **Planificador de Distribución**: Estima el número de trasteros por m² y calcula la inversión inicial en placas de chapa y sistemas de acceso.
2. **Modelo de Suscripción**: Simulador de tasa de ocupación progresiva y cálculo de ingresos recurrentes mensuales.
3. **Punto de Equilibrio (Break-Even)**: Proyección del número de meses necesarios para cubrir costes de explotación recurrentes (luz, seguros, software de gestión).

## Stack Tecnológico

- **Tecnología**: HTML5, Vanilla JavaScript y CSS3 Custom Properties.
- **Diseño**: Interfaz interactiva de carga ultrarrápida.
