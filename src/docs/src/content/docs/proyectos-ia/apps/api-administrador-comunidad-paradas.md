# api-administrador-comunidad-paradas

API de backend modular diseñada para la administración integral, control financiero y gestión de alquileres de propiedades inmuebles de la comunidad de propietarios Paradas.

## Características y Funcionalidades

1. **Gestión de Inmuebles**: Mantenimiento del catálogo de propiedades (pisos, locales, plazas de garaje) con información detallada de estado de ocupación y contratos.
2. **Control Financiero**: Gestión de cuotas de comunidad, cobros de alquileres y registro de gastos ordinarios/extraordinarios de la comunidad.
3. **Módulo de Inquilinos**: Registro de datos de contacto de inquilinos, vigencia de contratos, depósitos y avales de forma centralizada.

## Stack Tecnológico

- **Entorno de ejecución**: Node.js
- **Framework web**: Express.js
- **CORS y Middleware**: Configuración de seguridad integrada
- **Estructura**: Arquitectura limpia por capas (rutas, controladores, servicios)
