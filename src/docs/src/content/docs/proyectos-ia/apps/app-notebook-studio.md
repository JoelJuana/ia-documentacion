# app-notebook-studio

Entorno interactivo para estructurar cuadernos digitales de conocimiento, organizar fuentes de información, redactar capítulos y generar materiales de estudio.

## Características y Funcionalidades

1. **Gestión de Cuadernos Temáticos**: Creación y organización modular de cuadernos de investigación y proyectos documentales.
2. **Ingesta de Fuentes**: Consolidación de notas, enlaces web, extractos de documentos y referencias técnicas por capítulo.
3. **Editor Estructurado de Capítulos**: Organización jerárquica de secciones con vista previa limpia y exportación documental.
4. **Integración con Conocimiento Local**: Conector preparado para consultas semánticas sobre la base de conocimiento del ecosistema.

## Stack Tecnológico

- **Frontend**: React 18 + Vite
- **Estilos**: CSS Custom (Diseño editorial oscuro/claro adaptable)
- **Persistencia**: Firebase Firestore + LocalStorage fallback
- **Despliegue**: Firebase Hosting → `notebook-studio.gironacc.com`
