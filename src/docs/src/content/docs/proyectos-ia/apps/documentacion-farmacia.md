# documentacion-farmacia

Portal interactivo de control de calidad, auditoría y consulta de manuales de procedimientos normalizados de trabajo (PNT) para oficinas de farmacia.

## Características y Funcionalidades

1. **Gestión de PNTs**: Organización jerárquica de manuales de recepción de pedidos, dispensación de estupefacientes, formulación magistral y mantenimiento de equipos.
2. **Validación y Cumplimiento**: Lista de comprobación integrada para auditar el cumplimiento normativo exigido por las delegaciones de sanidad locales.
3. **Optimización de Lectura**: Buscador local integrado ultrarrápido y navegación en barra lateral optimizada para consultas inmediatas en el laboratorio o mostrador.

## Stack Tecnológico

- **Framework**: Astro (Starlight)
- **Despliegue**: Firebase Hosting
- **Organización del contenido**: Estándar de documentación técnica estructurado
